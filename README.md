# 傳說對決精彩片段篩選

用這個 Codex skill 從《傳說對決》（Arena of Valor）錄影中挑出值得留下的操作。每個判斷都對應到原片的一段時間，方便回看誰先控場、誰打出傷害，以及最後一擊是怎麼拿到的。

## 開始使用

下載這個 repo，在 Codex 中指定 [SKILL.md](SKILL.md) 和這次要處理的影片資料夾。把下方路徑換成自己的位置。英雄資料與校準案例隨 repo 提供，以後換一批錄影也能使用。

> 讀取 `~/Projects/aov-highlight-selector/SKILL.md`，幫我篩選 `~/Movies/傳說對決錄影`。先給我幾支值得留的，以及幾支最接近保留門檻的。每支附原片連結、時間點和理由，讓我確認標準。

確認標準後，可以直接要求成片：

> 依剛才的回饋檢查整批，把保留的片段剪好，另存到 `~/Movies/傳說對決精選`。用英雄和操作命名，附第一人稱敘述、文字檔與播放索引。

要接著做合輯，可指定每部只放一隻英雄，長度約 3–6 分鐘。素材多的按主題分集，素材少的可做短版，只有一支就沿用原成片。

## 判斷標準與參考資料

本人同一波四殺、五殺優先保留。雙殺、三殺則看進場角度、追擊、躲招、換裝或反打的難度。例如隊友先控住對手時，跟進補最後一下通常跳過；若自己抓準控制時間，讓大招同時打中多個目標，就有保留價值。更多已判過的邊界見[校準案例](references/校準案例.md)。

辨認英雄或裝備時，可在下載後用瀏覽器開啟[英雄圖鑑](references/英雄圖鑑/英雄圖鑑.html)與[實戰頭像對照](references/英雄圖鑑/實戰頭像對照.html)，或直接查閱[裝備機制](references/英雄圖鑑/裝備資料.json)。
