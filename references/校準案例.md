# 使用者已判過的邊界

以下編號僅供識別歷史案例，判下一批時以新片的畫面為準。

| 情境 | 判法 |
|---|---|
| 740 司空震跟隊友推高地，個人擊殺 5 到 9 | 留四殺。019 洛里昂是使用者點名跳過的個例，原因是主要靠隊友、個人傷害落點普通。 |
| 三個殘血被自己收掉，或側切拿乾淨雙殺後活著撤出 | 可留。混戰三殺後自己倒下通常跳過；一打多拿三殺另看。 |
| 231 莫拉接輔助大招，對手全程無法行動 | 跳過。652 亥犽接夸克大招切入，自己的大招同時打中多人收三顆，留，敘述寫出夸克先控制。 |
| 558 貝揚低兩等回頭撞暈，把對手留在塔下 | 留。塔有輸出，但把對手留在塔下是本人創造的機會。 |
| 潘因優勢很大，位移越塔收一隻殘血後撤 | 跳過。評價要看這個英雄的正常操作難度。 |
| 595 安格列開大落地鎖血，接著死神鐮刀觸發 | 留。分別看大招動作、底部鐮刀圖示與血條；單憑畫面變紅不能寫成殘血守塔。 |
| 布萊特開大延後傷害，扛過集火拿五殺 | 留，交代大招在戰鬥中起的作用。 |
| 758 蘇第二槍甩狙收掉已出視野的史蘭茲 | 強留。標題範例「傳說對決 蘇 第二槍甩狙收掉史蘭茲 達成漂亮雙殺」。辨別甩狙看準星轉向，盲狙看開槍前的視野，預判還要看提前瞄位。 |
| 759 蘇普攻補掉司空震 | 跳過。核對造成擊殺的那一下及技能狀態；先前架槍或擊殺提示本身都不足以證明是狙擊。 |
| 199 莉莉安換形三殺後殘血撤回，之後又陣亡 | 留到撤回成功。005 蘇則剪掉最後無成果的架槍。 |
| 隊友已在場，但本人低血量來回拉打、閃招，隊友傷害有限 | 可留。零擊殺開團後先倒、隊友收完通常跳過；單純躲招逃生屬加分。 |
